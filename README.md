# Greenland Sea Ice Analysis

Drone-based sea ice floe segmentation and characterization pipeline for visible-light and thermal imagery. Segments individual floes, measures their areas and shapes, and estimates the fractal dimension of floe boundaries as an indicator of ice fragmentation.

## Data Setup

### Placing images for batch inference

Drop images into a subfolder of `data/batch_input/`:

```
data/batch_input/
└── my_flight/
    ├── DJI_001_T.JPG    ← thermal image (auto-detected by pixel count < 1 MP)
    ├── DJI_001_V.JPG    ← visible image (auto-detected by pixel count >= 1 MP)
    └── ...
```

Then set `INPUT_FOLDER = "my_flight"` at the top of `batch_infer.py`.

### Annotating images for training

1. Annotate images in [CVAT](https://cvat.ai) using polygon labels named `ice`
2. Export as **Segmentation mask (PNG)** at the same resolution as the source image
3. Save pairs to `data/images/training/`:
   ```
   data/images/training/
   ├── flight_001.jpg
   ├── flight_001_mask.png
   ├── flight_002.jpg
   ├── flight_002_mask.png
   └── ...
   ```
4. Re-run the training script -- pairs are discovered automatically

## Scripts

### `scripts/binary_mask.py` -- Core Library

Imported by all inference scripts. Key API:

**`FloeSeparator(img_path)`** -- load and segment an image
- `preprocess(clahe_clip, clahe_grid, thresh_val)` -> `(gray_u8, rgb, mask_u8)`
  Applies CLAHE equalization then binary inverse threshold (255 = ice, 0 = sea).
- `split_erode_dilate_small(mask_u8, min_area)` -> `(labels, areas_m, centroids)`
  Erodes large components, runs connected components, dilates each floe back separately.
  Returns a 2D int32 label array (0 = sea, 1..N = floe ID), areas in m^2, and centroids.

**`characterize_floes(labels)`** -> `list[dict]`
Fits an ellipse to each floe contour. Returns per-floe dicts with:
`label`, `area_px`, `perimeter_px`, `semi_major_px`, `semi_minor_px`, `aspect_ratio`, `circularity`

**`compute_fractal_dimension(areas, perimeters)`** -> `dict`
Estimates the boundary fractal dimension *D* via OLS log-log perimeter-area regression.
Includes a 95% bootstrap confidence interval. Returns `valid`, `n_floes`, `D`, `r_squared`, `D_ci_low`, `D_ci_high`.

**`measure_raw_contours(mask_u8, min_area_px)`** -> `(areas_px, perimeters_px)`
Extracts areas and perimeters from the raw binary mask without morphological smoothing.

**`compute_average_temps(temp_arr, labels)`** -- per-floe mean temperature from a float temperature array.

**Motion tracking utilities** (for timelapse analysis):
`match_floes`, `track_floes_over_sequence`, `compute_avg_velocity_for_full_tracks`, `plot_floe_trajectories`

### `scripts/batch_infer.py` -- Batch Inference Pipeline

Processes all images in `data/batch_input/{INPUT_FOLDER}/`. Auto-detects image type: < 1 MP = thermal, >= 1 MP = visible. Supports both binary mask and UNet segmentation methods.

**Key config variables (top of file):**

| Variable | Default | Description |
|---|---|---|
| `METHOD` | `"binary_mask"` | `"binary_mask"` or `"unet"` |
| `INPUT_FOLDER` | `"thermalimages"` | Subfolder name inside `data/batch_input/` |
| `DRONE_HEIGHT_M` | `92.35` | Flight altitude in metres -- **update per flight** |
| `BM_CLAHE_CLIP` | `1.5` | CLAHE clip limit for binary_mask method |
| `BM_THRESH_VAL` | `75` | Binary threshold value (0-255) |
| `FRACTAL_MIN_AREA_M2` | `1.0` | Minimum floe area (m^2) for fractal dimension regression |

**Run:**
```bash
python scripts/batch_infer.py
```

**Outputs** per image in `outputs/results/batch/{folder}/{stem}/`:
- `mask.png` -- binary ice/sea mask
- `boundary_overlay.png` -- original image with yellow floe boundaries
- `floe_size_hist.png` -- histogram of floe areas (m^2)
- `pa_scaling.png` -- log-log P-A plot with fractal dimension *D* (dilated and raw)
- `floe_labels.npy` -- 2D int32 label array (0 = sea, 1..N = floe ID)
- `floe_stats.json` -- shape metrics per floe + metadata (GSD, fractal dimension)

## Model Architecture

**UNetSmall** (used by `training/unet.py`, `training/unet_thermal.py`, `training/unet_multiscale.py`, `infer.py`)
- 3-level encoder/decoder with skip connections
- ~700K parameters, CPU-friendly
- Loss: BCE + Dice

**UNet + ResNet18** (used by `training/unet_pretrained_colab.ipynb`, `batch_infer_visible_multiscale.py`)
- Pretrained ResNet18 encoder (ImageNet) + UNet decoder via `segmentation-models-pytorch`
- ~11M parameters, GPU recommended for training

Inference uses a **sliding-window** approach: tiles overlap and predictions are averaged to eliminate seam artifacts.

| Mode | Tile size | Stride | Used by |
|---|---|---|---|
| Visible (scratch) | 500 px | 250 px | `infer.py`, `batch_infer.py` |
| Thermal | 128 px | 64 px | `infer.py`, `batch_infer.py`, `compare_thermal.py` |
| ResNet18 visible | 750 px | 375 px | `batch_infer_visible_multiscale.py` |

## Fractal Dimension

Floe boundary complexity is estimated via the perimeter-area (P-A) scaling law:

```
log(P) = (D/2) x log(A) + log(k)   ->   D = 2 x slope
```

- *D* = 1: perfectly smooth (circular) boundaries
- *D* = 2: maximally complex/fractal boundaries
- Typical sea ice: *D* approximately 1.1-1.6

Two estimates are reported per image:
- **dilated** -- perimeters after erode/dilate morphological separation (smoothed boundaries)
- **raw** -- perimeters measured directly from the binary mask contours

Both include a 95% bootstrap confidence interval and log-log fit R-squared.
Floes smaller than `FRACTAL_MIN_AREA_M2` (default 1.0 m^2) are excluded from the regression.

## GSD (Ground Sampling Distance)

All measurements are converted from pixels to metres using:

```
GSD (m/px) = DRONE_HEIGHT_M x PIXEL_PITCH_M / FOCAL_LENGTH_M
```

Camera constants (fixed for this drone):
- `PIXEL_PITCH_M = 1.2e-5` m
- `FOCAL_LENGTH_M = 9.1e-3` m

At 92.35 m altitude: GSD approximately 0.1217 m/px.

**Update `DRONE_HEIGHT_M`** at the top of `batch_infer.py`, `infer_tif.py`, or `batch_infer_visible_multiscale.py` for each flight.

## Project Status and Known Limitations

**What works well:**
- Classical binary_mask method on thermal images with good ice/water contrast
- Thermal TIF pipeline with full temperature analysis
- Batch processing of large image folders
- Fractal dimension estimation with confidence intervals
- Floe shape characterization (area, perimeter, aspect ratio, circularity)

**Areas for improvement:**
- UNet models trained on limited data (1-10 labeled images) -- more annotations would improve accuracy
- Motion tracking is implemented in `binary_mask.py` but not exposed through batch scripts
- Thermal-to-visible registration (homography) is experimental and not integrated into the main pipeline
- The classical method requires manual tuning of `BM_THRESH_VAL` for different lighting conditions
- No automated GSD calculation from image EXIF/metadata -- drone height must be set manually

**Experimental scripts** in `scripts/experimental/` contain early prototypes (Canny edge detection, watershed segmentation, homography registration) that informed the current pipeline but are not actively maintained.
